### Homeworks (`homework_00` – `homework_11`)
Twelve problem sets covering core statistical and data science concepts, completed individually outside of class. Topics progress from Python fundamentals through statistical modeling and inference.

Fourteen guided in-class exercises designed to reinforce lecture material through hands-on analysis. Labs typically involve real-world datasets and are completed collaboratively.

### Projects (`project_01` – `project_03`)
Three larger-scale data analysis projects that integrate multiple course concepts. Each project involves sourcing data, performing exploratory analysis, building and evaluating models, and presenting findings.

## Setup

To run the notebooks locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/MatthewMandhyan/Stat207_clone.git
   cd Stat207_clone
   ```

2. **Activate the virtual environment**
   ```bash
   source .venv/bin/activate        # macOS/Linux
   .venv\Scripts\activate           # Windows
   ```

3. **Install dependencies** (if not already installed via the venv)
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch Jupyter**
   ```bash
   jupyter notebook
   ```
